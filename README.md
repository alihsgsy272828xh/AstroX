AstroX turns your AI chat tab into a hands-on Roblox Studio co-developer. A small browser extension adds a composer to your favorite chat site, a local bridge connects it to Studio, Blender, Figma and Blockbench, and the desktop app gives you one place to watch and steer the build.

Approve a numbered plan before anything changes. Attach exactly the context you want with @-mentions — skills, scripts, your Studio selection, saved checkpoints, or a live viewport frame. Every mutating call lands in a change journal with real one-click undo, and checkpoints let you restore a subtree before risky edits. WorkBench lets you edit and validate the skills the agent reads, while the Workshop lets you share or install skills and plugins with the community.

Everything runs on your machine under local, name-only accounts. No password, no cloud login, no bundled API keys — just an agent you can approve, inspect and rewind.
